在深度学习编译器（如 TVM、TensorRT、XLA）和推理引擎的图优化（Graph Optimization）阶段，**算子融合（Operator Fusion）** 是减少内存带宽瓶颈（Memory Bandwidth Bound）最核心的手段。

传统非融合执行时，`Conv` 的结果要写回 DRAM/VRAM，`BiasAdd` 再从 DRAM 读出计算后再写回，`ReLU` 又要读写一次——**中间产生的临时 Tensor 带来了极大的内存读写开销**。融合为 `ConvBiasReLU` 单 Kernel 后，中间结果直接储存在 GPU/NPU 的**寄存器（Register）或 L1 Cache** 中，从而带来数倍的性能提升。

---

## 1. 核心设计思路

实现图层面的算子融合，通常包含三个核心步骤：

1. **计算图抽象 (DAG Representation)**：定义 `Node`（算子）与 `Tensor`（边），建立节点间的输入/输出依赖关系。
2. **模式匹配与融合 PASS (Pattern Match & Fusion Pass)**：
* 遍历计算图，寻找满足 `Conv -> BiasAdd -> ReLU` 的线性依赖结构。
* **关键约束条件（Fusion Safeguard）**：被融合的中间节点（如 `Conv` 和 `BiasAdd` 的输出）**出度（Out-degree）必须为 1**。如果 `Conv` 的输出还要供给图中的其他分支使用，则不能直接擦除该节点。


3. **节点替换与图重构 (Graph Rewriting)**：将符合条件的 3 个节点替换为一个新节点 `Fused_Conv_Bias_ReLU`，重新接管输入/输出边，并擦除被融合的中间节点。

## 2. C++17 完整代码实现

下面的代码完整模拟了**计算图构建、模式识别、节点融合、图重构**以及**融合后的单 Kernel 计算执行**。

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <memory>
#include <unordered_set>
#include <algorithm>
#include <cassert>

// 算子类型定义
enum class OpType {
    CONV2D,
    BIAS_ADD,
    RELU,
    FUSED_CONV_BIAS_RELU, // 融合后的新算子类型
    CUSTOM
};

std::string op_type_to_str(OpType type) {
    switch (type) {
        case OpType::CONV2D: return "Conv2D";
        case OpType::BIAS_ADD: return "BiasAdd";
        case OpType::RELU: return "ReLU";
        case OpType::FUSED_CONV_BIAS_RELU: return "Fused_Conv_Bias_ReLU";
        default: return "Custom";
    }
}

// 计算图节点定义
struct Node;
using NodePtr = std::shared_ptr<Node>;

struct Node {
    std::string name;
    OpType type;
    
    std::vector<NodePtr> inputs;  // 父节点列表
    std::vector<NodePtr> outputs; // 子节点列表

    Node(std::string name, OpType type) : name(std::move(name)), type(type) {}

    // 添加单向依赖依赖关系
    static void add_edge(const NodePtr& src, const NodePtr& dst) {
        src->outputs.push_back(dst);
        dst->inputs.push_back(src);
    }

    // 断开两个节点间的依赖
    static void remove_edge(const NodePtr& src, const NodePtr& dst) {
        src->outputs.erase(std::remove(src->outputs.begin(), src->outputs.end(), dst), src->outputs.end());
        dst->inputs.erase(std::remove(dst->inputs.begin(), dst->inputs.end(), src), dst->inputs.end());
    }
};

// 计算图结构
class ComputationGraph {
public:
    std::vector<NodePtr> nodes;

    void add_node(const NodePtr& node) {
        nodes.push_back(node);
    }

    // 打印当前图的拓扑结构
    void print_graph(const std::string& title) const {
        std::cout << "=== " << title << " ===" << std::endl;
        for (const auto& node : nodes) {
            std::cout << "Node: [" << node->name << "] (" << op_type_to_str(node->type) << ")\n";
            std::cout << "  Inputs:  ";
            for (const auto& in : node->inputs) std::cout << in->name << " ";
            std::cout << "\n  Outputs: ";
            for (const auto& out : node->outputs) std::cout << out->name << " ";
            std::cout << "\n-----------------------------------" << std::endl;
        }
    }

    // =========================================================================
    // 核心算子融合 Pass： Conv2D + BiasAdd + ReLU -> Fused_Conv_Bias_ReLU
    // =========================================================================
    void optimize_fuse_conv_bias_relu() {
        std::unordered_set<NodePtr> nodes_to_remove;

        for (size_t i = 0; i < nodes.size(); ++i) {
            NodePtr conv = nodes[i];

            // 1. 匹配第 1 个节点：Conv2D
            if (conv->type != OpType::CONV2D || nodes_to_remove.count(conv)) {
                continue;
            }

            // 检查 Conv2D 约束：输出节点必须恰好只有 1 个（出度为 1），否则融合会破坏其他分支的数据依赖
            if (conv->outputs.size() != 1) continue;
            NodePtr bias = conv->outputs[0];

            // 2. 匹配第 2 个节点：BiasAdd
            if (bias->type != OpType::BIAS_ADD || bias->inputs.size() != 2 || bias->outputs.size() != 1) {
                continue;
            }
            NodePtr relu = bias->outputs[0];

            // 3. 匹配第 3 个节点：ReLU
            if (relu->type != OpType::RELU) {
                continue;
            }

            // 匹配成功！建立新节点 Fused_Conv_Bias_ReLU
            std::string fused_name = "fused_" + conv->name + "_" + bias->name + "_" + relu->name;
            NodePtr fused_node = std::make_shared<Node>(fused_name, OpType::FUSED_CONV_BIAS_RELU);

            // 重构输入关系：
            // fused_node 的输入包含：Conv 的输入 (Input Feature Map) + Conv 的权重 (Weights) + BiasAdd 的偏置 (Bias)
            for (const auto& conv_in : conv->inputs) {
                Node::add_edge(conv_in, fused_node);
            }
            // 找到 BiasAdd 节点中除了 Conv 之外的另一个输入（即 Bias Tensor）
            for (const auto& bias_in : bias->inputs) {
                if (bias_in != conv) {
                    Node::add_edge(bias_in, fused_node);
                }
            }

            // 重构输出关系：将原 ReLU 的所有子节点重定向到 fused_node
            std::vector<NodePtr> relu_outputs = relu->outputs;
            for (const auto& relu_out : relu_outputs) {
                Node::remove_edge(relu, relu_out);
                Node::add_edge(fused_node, relu_out);
            }

            // 断开旧节点连接
            Node::remove_edge(conv, bias);
            Node::remove_edge(bias, relu);

            // 标记需要剔除的旧节点
            nodes_to_remove.insert(conv);
            nodes_to_remove.insert(bias);
            nodes_to_remove.insert(relu);

            // 加入新节点
            nodes.push_back(fused_node);
        }

        // 从图中正式移除被融合淘汰的节点
        nodes.erase(std::remove_if(nodes.begin(), nodes.end(),
                                  [&](const NodePtr& n) { return nodes_to_remove.count(n) > 0; }),
                    nodes.end());
    }
};

```

## 3. 融合后的 Kernel 底层执行模拟 (C++ SIMD/Loop Level)

在融合 Pass 将图节点替换之后，底层运行时（Runtime）会调用对应的融合执行 Kernel。以下演示该融合 Kernel 的 C++ 标量/向量化实现：

```cpp
// 模拟执行：Fused Conv2D + BiasAdd + ReLU 运行在单次循环中
// 避免中间特征图 (Feature Map) 写回与读取 DRAM
void fused_conv2d_bias_relu_kernel(
    const float* input, const float* weight, const float* bias, float* output,
    int N, int C, int H, int W, int K, int R, int S, int pad, int stride) 
{
    int H_out = (H + 2 * pad - R) / stride + 1;
    int W_out = (W + 2 * pad - S) / stride + 1;

    for (int n = 0; n < N; ++n) {
        for (int k = 0; k < K; ++k) { // 输出通道
            float b = bias[k];       // 1. 将 Bias 提至寄存器
            for (int oh = 0; oh < H_out; ++oh) {
                for (int ow = 0; ow < W_out; ++ow) {
                    
                    // 累加器初始化为 Bias 值 (把 BiasAdd 提前融入累加初值)
                    float sum = b;

                    // 卷积计算
                    for (int c = 0; c < C; ++c) {
                        for (int r = 0; r < R; ++r) {
                            for (int s = 0; s < S; ++s) {
                                int ih = oh * stride - pad + r;
                                int iw = ow * stride - pad + s;
                                if (ih >= 0 && ih < H && iw >= 0 && iw < W) {
                                    sum += input[((n * C + c) * H + ih) * W + iw] * 
                                           weight[((k * C + c) * R + r) * S + s];
                                }
                            }
                        }
                    }

                    // 2. 算子融合：在寄存器中直接执行 ReLU，不经过内存存取！
                    output[((n * K + k) * H_out + oh) * W_out + ow] = std::max(0.0f, sum);
                }
            }
        }
    }
}

```

## 4. 测试与验证代码

```cpp
int main() {
    ComputationGraph graph;

    // 创建虚拟张量节点
    auto input = std::make_shared<Node>("input", OpType::CUSTOM);
    auto weight = std::make_shared<Node>("weight", OpType::CUSTOM);
    auto bias = std::make_shared<Node>("bias", OpType::CUSTOM);

    // 创建需要融合的三个连续节点
    auto conv = std::make_shared<Node>("conv1", OpType::CONV2D);
    auto bias_add = std::make_shared<Node>("bias_add1", OpType::BIAS_ADD);
    auto relu = std::make_shared<Node>("relu1", OpType::RELU);

    // 创建后续输出节点
    auto next_op = std::make_shared<Node>("next_op", OpType::CUSTOM);

    // 构建原始依赖图：
    // input, weight -> conv1
    // conv1, bias   -> bias_add1
    // bias_add1     -> relu1
    // relu1         -> next_op
    graph.add_node(input); graph.add_node(weight); graph.add_node(bias);
    graph.add_node(conv);  graph.add_node(bias_add1); graph.add_node(relu);
    graph.add_node(next_op);

    Node::add_edge(input, conv);
    Node::add_edge(weight, conv);
    
    Node::add_edge(conv, bias_add);
    Node::add_edge(bias, bias_add);

    Node::add_edge(bias_add, relu);
    Node::add_edge(relu, next_op);

    // 打印融合前的拓扑图
    graph.print_graph("BEFORE Operator Fusion");

    // 执行融合 Pass
    graph.optimize_fuse_conv_bias_relu();

    // 打印融合后的拓扑图
    graph.print_graph("AFTER Operator Fusion");

    return 0;
}

```

## 5. Senior/Staff 级别考点延伸与深度回答

在面试中如果写出上述 Pass 逻辑，可以主动提及以下编译期优化的硬核细节：

1. **出度校验 (Out-degree Check) 的重要性**：
* 为什么 `conv` 和 `bias_add` 的输出节点出度必须为 1？因为如果中间节点 `conv1` 的结果还被图中另一个分支（例如 Residual 连接）使用，一旦直接替换并擦除 `conv1`，另一个分支就会找不到输入数据导致图断裂。


2. **Horizontal vs. Vertical Fusion (水平融合 vs. 垂直融合)**：
* **Vertical Fusion（垂直融合，如本题）**：沿计算图纵向依赖链进行融合（`Conv -> Bias -> ReLU` 或 `MatMul -> Add`），消除访存。
* **Horizontal Fusion（水平融合）**：将图中互不依赖但输入尺寸相同的并行算子合并（例如 Transformer 中的 `Q, K, V` 矩阵乘法合并为单个大的 `QKV GEMM`），以提高 GPU 算力利用率（Wave Occupancy）。


3. **代码生成 (Codegen) 与 TVM/XLA 路线**：
* 在现代 AI 编译器（如 Apache TVM 或 PyTorch Inductor）中，除了手写固定 Pattern 替换之外，更通用的是 **Loop-level Fusion (基于 Loop Nest 的融合)**。通过将算子的表达式表示为 Halide 风格的 IR，编译器会自动将内层循环合并，并通过 LLVM 或 NVPTX 直接生成高效的 CUDA / CPU 汇编代码。
